<h1 align="center">Proxirae</h1>

A Windows proxy client for SOCKS5 and HTTPS proxies, providing rule-based routing for TCP and UDP traffic.

## Installation

Download the latest release from the [Releases](https://github.com/fralorange/Proxirae/releases/latest) page.

For installation instructions and help configuring your first proxy rule, see the [Quickstart](https://github.com/fralorange/Proxirae/wiki/Quickstart).

## Features

- **Rule-based routing** - configure rules to proxy, bypass the proxy, or block connections based on processes, hosts, and ports.
- **Proxy management** - configure and manage proxy servers from the desktop interface.
