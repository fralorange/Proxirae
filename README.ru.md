<h1 align="center">Proxirae</h1>

Прокси-клиент для Windows с поддержкой SOCKS5 и HTTPS и маршрутизацией TCP- и UDP-трафика на основе правил.

## Установка

Скачайте последнюю версию Proxirae со страницы [Releases](https://github.com/fralorange/Proxirae/releases/latest).

Инструкции по установке и настройке первого прокси правила доступны в руководстве [Быстрый старт](https://github.com/fralorange/Proxirae/wiki/Quickstart-ru-RU).

## Возможности

- **Маршрутизация на основе правил** - настройка правил для перенаправления трафика через прокси, обхода прокси или блокировки соединений на основе процессов, хостов и портов.
- **Управление прокси-серверами** - управление прокси-серверами и настройка параметров подключения через графический интерфейс.
